# 🚗🔥 Steel Havoc

Steel Havoc is a car combat Android game developed using **Kotlin** and **Jetpack Compose** in Android Studio.

The game is inspired by classic vehicle combat games, where the player drives around the battle arena, fights enemy cars, fires weapons, and tries to survive.

## 🎮 Features

- 🚗 Player-controlled combat car
- 🤖 3 AI enemy cars
- 🔫 Weapon and shooting system
- 💥 Explosion effects
- ❤️ Player and enemy health system
- 🚧 Car and map collision system
- 🎯 Enemy AI movement and combat
- 🕹️ Hold-based movement controls
- 🎵 Main menu background music
- 🎸 Heavy battle music during gameplay
- 🔊 Gunfire and explosion sound effects
- 🏁 Game result system
- 📱 Android mobile gameplay

## 🛠️ Technologies Used

- Kotlin
- Jetpack Compose
- Android Studio
- Gradle
- Git & GitHub

## 🕹️ Controls

The player can control the combat vehicle using on-screen buttons:

- ⬆️ Move Forward
- ⬇️ Move Backward
- ⬅️ Turn Left
- ➡️ Turn Right
- 🔫 Fire Weapon

## 🤖 Enemy System

Steel Havoc contains three AI-controlled enemy vehicles.

The bots can move around the battle arena, detect combat situations, fight the player and other vehicles, and take damage during battle.

## 💥 Combat System

Players and enemy vehicles have health points.

Weapon hits reduce health. When a vehicle loses its health, explosion effects and the game combat system handle its destruction.

## 🔊 Audio

The game includes different audio effects to make combat more immersive:

- Main menu music
- Battle music
- Gunfire sound
- Explosion sound

## 📱 How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Start an Android Emulator or connect an Android device.
5. Click **Run ▶**.
6. Play Steel Havoc.
